# 先发布30位知名人物：作品定位与发现入口（2026-10-11）

原计划新增50位，本次按用户安排先发布30位，系列由50人扩展到80人；剩余20位留待明天继续。优先考虑广泛的教材、阅读与公众认知入口，同时延续哲学、教育、史学、文学美学、公共治理与系统思想的系列范围。人物的领域和知名度不同；并非每位都是同样广为人知的专业哲学家，惠施更多面向思想史读者；余20位中的熊十力、牟宗三、唐君毅等也偏向专业哲学受众。

## 发现与收藏潜力

不再把“GitHub无人发布”当必要条件。孔子、老子、庄子、孙子、王阳明、鲁迅等已有相关作品，我们按频繁发生的任务、可以立刻看懂的成果与独特使用边界设计新的工作流，不复制其他仓库的设定、文案与示例。

人物首页的全部相关推荐折叠展示，保留每个链接，让用途与一分钟示例保持易见。总仓库首页优先展示10个辨识度高且容易试用的入口：孔子学习迁移、孙子民用策略、老子流程减法、庄子视角转换、王阳明行动验收、鲁迅选择性借鉴、苏轼理解迁移、胡适假说研究、诸葛亮专注计划、曾国藩长期习惯。推荐顺序由 catalog/skills.json 的 discovery_rank 维护，目录生成器读取同一数据；不是实际星数排行。

每个人物仓库首页均展示具体适用问题、交付顺序、一个一分钟示例、安装命令与用途差异。知名度提高识别机会，能复用的工作流才是收藏理由。没有数据支持精确星数、增长率或必然“爆款”的保证，没有购买星标或发送外部推广消息。

## 资料与归属

古代作品以已读的公开电子章段为依据，不声称初刊、全书或全部异文已经校勘。孙膑的赛马例证来自司马迁《史记》，不冒作孙膑《兵法》原文；管子、鬼谷子等传承和作者归属有限度。董仲舒与惠施的史传、后人记述，陆九渊的书信与门人回顾分别注明。

今天发布的作品仅使用资料卡已读章段或公开文章，不把后人解释当本人亲笔。所有步骤、工作表与虚构示例均为项目现代转译，不是人物对现代事项的背书。其余20位的材料、代码与示例已准备并保存在本地，尚未计入公开目录；不在此文中给尚不存在的仓库添加可安装链接。

## 质量与发布

每个作品有6步专门流程、3个原创虚构示例、首例5项工作表、资料卡、边界、10个待运行行为评测场景和适用的确定性辅助工具。本次30个新作品共330项本地单元测试通过，另检查格式、文档完整性、内部链接与真实工具输入输出。300个模型行为场景尚未在独立客户端执行；这些场景不能被记作通过。安装发现、CI及结构检查不证明实际模型分析质量或长期用户效果。

全部从 thinkers-skill-template 创建公开人物仓库，直接提供根目录 SKILL.md 与安装命令，不创建 GitHub Releases。只有实际提交并推送后才登记目录为 published。统一Topics、About Website、系列标识、回链、推荐链接与模板快照沿用现有同步机制。唯一作品目录维护入口仍为 catalog/skills.json。
