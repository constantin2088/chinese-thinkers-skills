# 选一个真实问题，试一次方法

下面的输入可直接复制。把方括号替换为自己的材料；资料不足时应先询问或列出缺口。案例是项目原创虚构场景，用于展示输入与预期产物，尚未作为独立客户端模型评测结果。

<a id="hypotheses"></a>

## 胡适：让争论落到可证伪假设

[胡适 Skill](https://github.com/constantin2088/hu-shi-hypotheses-skill)

```text
用胡适 Skill 分析：团队认为“用户不活跃是因为功能不够多”。
已有材料：[近四周活跃数据、访谈片段、用户分组、已知变化]。
先把口号改成可验证的问题，再列两个替代解释。
输出：假设、需要的证据、可能推翻假设的结果、最小检验、停止线。
不要把相关性写成因果；没有材料时先说明缺口。
```

**检查点**：能否说清什么结果会让团队放弃原解释；不要只有支持原观点的证据。

<a id="strategy"></a>

## 孙子：决定一件民用项目做不做

[孙子 Skill](https://github.com/constantin2088/sun-tzu-strategy-skill)

```text
用孙子 Skill 比较一个民用项目的三个选项：立即全面推进、小范围试点、暂缓。
背景：[目标、预算、团队能力、时间、依赖条件、可退出成本]。
把成本、条件和不确定性列出来，比较不行动的代价。
输出：选项比较表、缺失信息、推荐与理由、撤退条件、下一次复核时间。
不得假装已经知道竞争方动向，也不要把兵法比喻当成现实证据。
```

**检查点**：推荐是否包含“不做”和退出条件，是否把未知情况明确留下。

<a id="evidence"></a>

## 陈寅恪：两份材料冲突，怎样判断

[陈寅恪 Skill](https://github.com/constantin2088/chen-yinke-research-skill)

```text
用陈寅恪 Skill 研究两份说法不一致的材料。
材料 A：[内容、作者、时间、出处与定位]。
材料 B：[内容、作者、时间、出处与定位]。
先做来源和立场检查，分清事实陈述、转述与推断，再比较矛盾位置。
输出：证据分层表、互证关系、仍不能确定的事项、后续查证路径。
没有看到的原文不得编引语、页码或年代。
```

**检查点**：推断是否与材料事实分开，无法确定的部分是否明确保留。

<a id="marketing"></a>

## 叶茂中：把顾客的矛盾变成可检验实验

[叶茂中 Skill](https://github.com/constantin2088/ye-maozhong-skill)

```text
用叶茂中 Skill 分析一个虚构的工作日健康午餐服务。
观察：用户想吃得健康，但午休短、嫌选择麻烦，价格也敏感。
现有证据：[访谈原话、订单数据、服务限制]。
先区分已经观察到的冲突和我们的解释，再给两个产品表达方向。
输出：冲突图、证据缺口、两个小实验、判断指标、失败与停止条件。
不要编造调研结果，不把制造焦虑作为产品卖点。
```

**检查点**：是否从真实证据出发；两个方向能否被实验区分，而非仅改广告词。
