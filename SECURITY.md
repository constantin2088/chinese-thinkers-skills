# Security

This hub contains static documents, SVG artwork, a JSON catalog and a small local validation script. It needs no credentials, API key, browser permission, network daemon or persistent background service.

For a vulnerability, avoid sharing sensitive reproduction data in public issues. Use GitHub's private vulnerability reporting if enabled or contact the maintainer privately through an appropriate channel.

Do not run or install a contributed Skill without inspecting its content and requested permissions. Historical or philosophical branding does not imply safety or authority.
