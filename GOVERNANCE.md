# Governance / 治理

This is an independently maintained collection under GitHub account `constantin2088`.

- Maintainer owns release and merge decisions.
- Contributors can propose work through Issues and Pull Requests.
- Changes to a thinker's factual attribution require stronger evidence than purely editorial changes.
- The hub is an index, not a blanket endorsement of each published Skill's answer.
- No planned entry should be silently relabeled as released.
- An independent repository must remain clearly attributed to its original authors and licenses.

Proposals for additional maintainers are welcome after consistent, source-backed contributions.
